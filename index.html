Building software end to end

I'm an IT student who got into full stack development by wanting to build something specific enough that no template fit. My most-used project is a chess tournament pairing system: a console-based Swiss pairing algorithm I rebuilt as a Spring Boot REST API with a live, board-themed frontend, because pairing players by hand every round doesn't scale.

The same instinct runs through everything else: a Pokédex REST API in ASP.NET Core with real input validation, an e-commerce and inventory system built with a team, and browser games where I learned to debug things that only break at 60 frames a second.

I like the full stack for one reason: a well-shaped database, an API contract that makes sense, and a frontend that stays out of the way.
